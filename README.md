# Modern C++ Design Patterns

一个系统整理经典设计模式的现代 C++ 实战项目。

## 项目目标

- 用现代 C++ 重新实现 23 种经典设计模式
- 展示 std::unique_ptr、std::shared_ptr、std::variant、std::visit、
  concepts、ranges、std::println 等现代特性的工程用法
- 提供可编译、可运行、可测试的完整示例
- 帮助开发者理解设计模式的核心思想与适用场景

## 模式分类

### 创建型
- 单例模式 Singleton
- 简单工厂 Simple Factory
- 工厂方法 Factory Method
- 抽象工厂 Abstract Factory
- 生成器 Builder
- 原型 Prototype

### 结构型
- 适配器 Adapter
- 桥接 Bridge
- 组合 Composite
- 装饰器 Decorator
- 外观 Facade
- 享元 Flyweight
- 代理 Proxy

### 行为型
- 责任链 Chain of Responsibility
- 命令 Command
- 迭代器 Iterator
- 中介者 Mediator
- 备忘录 Memento
- 观察者 Observer
- 策略 Strategy
- 状态 State
- 模板方法 Template Method
- 访问者 Visitor
